## 1. DNS and HTTPS for the backend

1. In Route 53, hosted zone `wonek.com`, add one record:
   `ayura-api.wonek.com  A  167.233.158.114  TTL 300`. Change no other record.
2. When `dig +short ayura-api.wonek.com` returns that address, run on the server:
   `/opt/ayura-assistant/enable-https.sh`. It gets the certificate with certbot
   (webroot), adds the nginx HTTPS site and reloads nginx. Check that

   `https://assistant-api.wonek.com/api/health/ready` and
